## 从仓库使用

源码仓库不包含本机账号配置、数据库、截图、历史data档案、备份和下载的CLI。示例配置见 `config/{staged/taobao.example.json,plugin/taobao-coin.example.json}`、`accounts/accounts.example.yaml` 和 `.env.example`；复制为本地配置后填写设备、模型环境变量和工作区路径。示例中的历史data/recipe索引需要自己的初始化或探索产物，不能当作已带齐的可执行状态。

历史原图回放测试依赖本地私有证据，不保证在全新克隆中直接运行完整测试。插件打包源码和两个宿主包已纳入版本管理；本地安装方式见下方插件说明。

## 运行

```bash
./node_modules/.bin/tsx server/meter.ts   # 模型计量代理 3426
./node_modules/.bin/tsx server/panel.ts   # 面板 8787，HTTP 请求只入队
```

面板访问：本机 http://127.0.0.1:8787 ，同局域网使用主机 IP。worker 通过显式入口 `server/worker.ts` 启动，未启动时队列不会自动操作手机。当前每日9点任务保持暂停，真机验证完成仍须用户确认后才可恢复调度。

```bash
./node_modules/.bin/tsx --experimental-test-module-mocks --test tests/*.test.ts
./node_modules/.bin/tsx runner/workflow.ts --validate <task.yaml>
```

## 当前机制

- 执行期收集实时任务清单；无效观测保留为未知，禁止推断为无任务。
- 动作前确认任务面板，动作后独立核对同一任务配额；档位20/20不等于全部任务完成。
- 未知任务依据实际说明受限探索；候选配方须独立验证后才能复用。修改说明或动作必须重新验证。
- 实际余额净增与流程完成状态分开；有收益但存在错误可记部分完成，奖励估计不能入实际收益账。
- HTTP面板只负责持久入队；显式worker串行消费，公共设备入口共享锁。job_id与真实run_id分别保存。
