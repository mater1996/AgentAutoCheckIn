# 公共导航接线实现

本轮接通第一步的离线链路。只有 `navigationPolicy: "current-text-v1"` 与 `localActivityNavigation: true` 同时启用才选当前文字判据；未配置 policy 保持 legacy。未改生产运行配置、次数或批执行。

`runtime.ts` 在 open_app / enter_activity / open_list 先调用当前观察检查器。明确 home / landing 不请求完整 AI 面板；panel 仍由已批准的 `ai-panel-v1` 读取任务与余额。当前文字判据的 panel 结果只决定进入面板读取，不替代 AI 的业务数据。真正未知页在非 scriptValidation 模式至多对同一 frame id 调用一次 `navigation-reader-v1`，输入原 PNG，输出仅 home / landing / panel / blocked，以及唯一领淘金币或去赚金币及 bounds。schema 不接受 next、action、余额或任务数组。

reader 保存私有原响应、manifest、SHA256 和 usage；共享 session/stage 时间与调用预算。派发独立重验同一原 PNG、owner、frame、manifest、原响应、stage 和 expectedCheckpoint，检查 15 秒新鲜度、当前预算、唯一目标及安全 bounds，不二次询问模型，不放行任意坐标。已有 dispatch 对象身份及同帧消费规则继续适用。未知派发不能重放；未见新观察到达不能确认。独立登录/遮挡/未知模态不增加 skip 或任务权限。

`navigation-records.jsonl` 是私有会话记录，包含实际 observation pageKind（检查器 / AI panel / reader / unknown）、frame、stage、attempt、expectedCheckpoint、PNG/OCR 路径及 `systemObservation` 引用；导航动作记录 pending→sent/unknown，随后新观察确认 arrival 或 unknown。stage 意图不填充实际 pageKind。记录复用既有 runtime 观察及 engine stage 结果，没有另建执行器，也不把这些记录加入共享候选脚本。

`main.ts` 封存 navigation reader / records / system observation 和 audit 依赖；真实 plan 读取字节独立保存在 `plan-input.json` 与 `plan-input-manifest.json`，含来源、SHA256、字节数，并受原有 source snapshot 不变检查。plan 不进入共享脚本候选。

`verifyAuditActivityNavigation` 显式接收 policy，并由原 navigation stages / recovery 审核按 session config 传入。current 策略读取同帧 raw OCR，或重验已保存 reader / panel 证据，不启动模型、不执行 OCR。legacy 路径仍使用原检查器。navigationPolicy 参与实现配置指纹；current 依赖要求有会话源码归档。旧 whole-session 零模型资格条件不变，reader 或 AI panel 调用不能因此计为旧稳定成功。

离线测试使用 run223 原首页 PNG/OCR、历史 201 landing 和 195 panel，全部可写路径复制到 scratch。路径、frame id、采样时间与转场是 synthetic，不声称历史帧是新采样或真实手机到达。通过真实 engine/runtime 验证 home→landing→panel 两次点击、明确导航零模型；AI panel 测试与歧义 reader 响应均为明确 stub。覆盖错误 owner、过期帧、source/响应篡改、stage 错绑、重复/危险 bounds、panel schema 误用、未知派发不重发、无到达不确认、模型预算、同帧 once、超时后不派发及 audit 同策略重放。

限制：尚未真机验证、调用生产模型或写生产 DB/cron；未接次数/批循环；未新增通用白屏重启或扩大 entry recovery；系统 Activity/task 仅旁证，不能作为到达或业务回执。路由记录当前覆盖公共导航动作，非公共任务动作仍保留原 runtime/engine/controller 证据；不声称已统一所有任务执行。reader 的视觉判断仍有模型误识别风险，保存的结构和来源检查不能证明模型看得正确。
