# AI辅助稳定脚本推进方案

用户最新明确授权：继续把所有任务达成稳定脚本跑通状态；有问题及时问；脚本随时可调用AI判断下一步。本文件覆盖旧验收方案中的强制零模型条件，其余真实回执/正收益/账号归属/不扩任务授权不变。

## 稳定标准

脚本承担可复用执行过程，AI可读页面、决定当前下一步、核验要求与回执，不算人工补救。每类相同适用过程至少两个独立正常入口session成功、无聊天手工给坐标或修账、当前任务真实回执、正确资产页两新帧稳定正增量、证据与执行源码归档、预算与清理通过。记录失败次数和AI开销，不以代码测试数量代替稳定；改动影响该执行过程时重新验证，不追求不相关源码全相同。旧whole-session-zero-model报告保持历史，不把AI成功伪装纯脚本。

已学16类详见data/evidence/plans/stable-scripts-20261101/tasks.json，首次学习均有来源。当前run218发现精选好物AI辅助完整正常入口一次成功、+50；只作一次证据。新模式其他类型尚未重复验证。

2. 继续视频/连续浏览实际可用任务复验，每项累计两个独立成功才标稳定。今日已执行但仍有quota须按要求和次数记录，不能以“名字今日出现过”永久挡第二次验收。
3. 补齐已学到访领奖、店铺等现有候选与配置入口。只使用确认过的普通领奖/浏览，不领其他档位。

5. 每轮最新完整任务列表更新do/skip/pending、重复次数及下一步。搜索/答题/游戏/邀请/安装/跨App/登录授权/消费等保持skip或待用户决策，任务名不是授权。

## 验证和止损

已有合同先复用配置开展真机，代码改变先复现测试并做必要回归，前备份独立成功后live，手机串行独占且息屏读回。AI辅助稳定报告另外版本化，不能直接移除旧审计全部限制来跑绿。若当前任务缺席/日限，记录具体阻塞与后续条件；若需要扩大任务类型或改变执行方案及时问用户，不循环补像素或只修验收器。
