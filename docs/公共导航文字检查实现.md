# 公共导航文字检查实现

本文件记录已批准第一步中的离线检查器部分。入口冻结为 `inspectCurrentActivityNavigation(frame: DeviceFrame, owner: {package: string; userId: number}): Promise<ActivityNavigationInspection | null>`，位于 `runner/staged/activity-navigation.ts`。未重写 legacy `inspectLearnedActivityNavigation`。runtime/device 接线由各自修改负责，本文件不声明真机验收。

- home 返回 `state: home`、`version: home-text-v1` 和当前“领淘金币”文字框中心 tap。要求唯一的领淘金币、推荐、搜索、消息、购物车、我的淘宝，检查顶部/搜索/入口/底栏的相对结构。保留原 home 关键 anchors 范围。
- landing 返回 `state: landing`、`version: landing-text-v1` 和当前唯一“去赚金币”文字框中心 tap。独立可读身份只接受 `淘金币` 或原始 OCR 的 `币淘金币`；身份位于上方左侧、目标在下方同列，按屏幕比例和间距检查。没有历史像素、参考文件读取或历史坐标 ±5 gate。
- panel 仅在出现明确面板标题时委托原有当前文字 `panel-text-v4` 分支，结果必须为 panel 且版本匹配；不携带旧 home/landing fallback，不返回导航动作。原文字列表、quota、描述、按钮及 raw/refined 行修正约束沿用。

home/landing 的 source 为 `activityHomeTextSource` / `activityLandingTextSource`，`files: []`；sourceRunId 198/200 说明来源，不授权当前动作。每个结果绑定输入 frameId 和实际当前 PNG 的 SHA-256。

输入必须匹配淘宝 package 与有效 user、1080×2400、非空 frameId、整数 capturedAt、有效 PNG 路径、完整合法文字框、无 observationError。读取同路径 `.ocr.json`，要求 Apple Vision 引擎、单页、page.file 与当前 PNG 路径完全一致以及正确尺寸；PNG 实际格式、尺寸、页数也必须合法。两份 OCR 全体行扫描登录/验证/授权/弹窗/广告等风险，不以正文 refinement 隐藏 raw 风险。

home/landing 只对关键导航值与 bounds 核验 raw/refined 一致：文字和四边坐标精确一致、关键重复拒绝，不要求全屏非关键正文和行顺序相同。正文修正不影响导航。目标框上其他 OCR 重叠拒绝；landing 身份框也检查重叠。关键导航文字仍不得由 refinement 猜测修复。现有 home 缺“淘”的情形不新增 OCR 修复流程，也不调用模型。

真实原件结论：run223 两张 home 从 legacy 拒绝变为新 API 接受；run201 两张与 run214 一张 landing 接受；run200 原始身份为“币淘金市”，可读性不足，拒绝且不作错字别名；195/203/209 panel 保留 panel-text-v4。历史文件均未修改。

测试在 `tests/staged-navigation-current-text.test.ts`。新增 landing、panel、正文 refinement 和 raw-only 目标重叠修复均先观察 RED 再实现 GREEN。负例覆盖 owner/package、normalized 重复、登录/raw 风险、无身份/仅目标、错布局/游戏能量位置、关键 raw 冲突、非法框、来源绑定和 PNG；正例补当前坐标超过历史 ±5 与装饰像素变化。合成样本在 `/Users/mater/.hermes/cache/scratch/navigation-current-text-*` 复制原 PNG/raw 后显式重定位 page.file，标为 synthetic，不称为新采样或真机证据。


限制：文字检查与路径绑定不能检测所有无文字图标遮挡或“像素已经变、OCR 仍旧”的情况，也不是 PNG 与 OCR 的密码学同帧证明。检查器不授予派发权限；新鲜度、未消费帧、未决动作、预算和到达检查仍须由 runtime/dispatch/audit 同版本接线完成。未使用真机、业务模型、DB、cron；未运行全量测试。
