# CLI插件实施与验收

本次按已确认方案改造，范围是公共业务MCP、两个Skill、Claude/Codex包、状态迁移与离线接线。没有新真机任务、模型调用或调度启用。修复、合并验证与独立复核已完成，下文按实际命令与证据列出。

## 之前与现在

| 之前 | 现在 |
| --- | --- |
| TS用独立图像请求逐次问模型，父会话常需外层监督 | CLI宿主可调用业务MCP；脚本遇到问题返回原图、prompt和decisionId，当前Agent答复后续跑原Promise与attempt |
| 执行/总结/维护边界不清晰 | 两个Skill：run-activity负责执行及结束报告；explore-and-review负责全活动/单任务复盘或明确授权探索，候选交调用方维护 |
| 账本在db/、批次和知识索引在data多种JSON | data/checkin.db为权威数据库；runner/storage保存访问和迁移源码；迁移后业务文档不回退到旧JSON |
| 长日志、截图、嵌套模型结果与业务记录混放 | 业务状态入库；evidence保留原始截图和长日志，通过execution/attempt/run关联 |
| 目录存在不等于知识被加载 | get_activity_context按配置scope读取knowledge文件，返回路径、hash和正文 |

## 交付入口

```text
checkin-platform/
├─ plugin-source/                 公共Skill/参考文档/宿主模板
│  └─ skills/
│     ├─ run-activity/SKILL.md
│     └─ explore-and-review/SKILL.md
├─ plugins/
│  ├─ claude/checkin/              Claude原生插件包
│  └─ codex/checkin/               Codex兼容格式插件包
├─ runner/
│  ├─ mcp/                        service/server/同Agent判断桥
│  ├─ storage/                    schema/访问/迁移
│  └─ staged/                     复用的执行、回执、核账和设备后端
├─ config/plugin/taobao-coin.json  正常插件配置，保留历史batch
├─ knowledge/apps/taobao/activities/tb_coin/
├─ data/checkin.db                唯一权威账本与结构化状态
├─ data/backups/                  独立迁移验证副本、每次live前备份
├─ db/checkin.db                  迁移前原件，不再写入
└─ evidence/<executionId>/        每轮证据、任务子目录、问题和报告
```

安装与使用命令见 [插件说明](../plugin-source/README.md)。实际安装校验使用隔离HOME和CLI配置，不修改日常CLI配置。生成包引用CHECKIN_WORKSPACE的真实TS后端，不携带数据库或凭据。默认设备关闭；授权真机时另启设备能力，当前应用重启能力单独启用。

MCP当前12工具，包括上下文、流程列表、begin、observe、execute_recipe、submit_decision、act、recover、cancel、状态、finish、review。以tools/list为准；不提供虚构reconcile_task工具。execute-task内部完成回执、结算、落账。图片使用text+image content，不使用会导致Codex优先文本化的非空structuredContent。

执行期skipReview且archiveKnowledge=false：保留事实、截图、账本、问题和报告，不写长期任务/阶段知识。宿主本身的文件工具仍由宿主权限控制，插件不宣称能沙箱隔离任意编码Agent。
