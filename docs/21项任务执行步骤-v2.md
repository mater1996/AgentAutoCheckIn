# 21项任务：决定、执行步骤与核验（v2）

这是离线步骤方案，没有操作手机。当前快照日期2026-11-01；执行前须刷新完整清单。8项候选有条件步骤，3项待确认只有了解分支，10项跳过明确不操作。新页面未实测，所以具体倒计时位置、搜索词、完成原文、入口坐标不编造，作为现场观察条件。

## 每项候选的共同前后步骤

1. **刷新与建档**：重新收全当前列表；比对任务名、说明、额度和奖励条件。新建attemptId，保存当前截图与正确资产页余额。旧快照变化则重做决策。 工具：OCR主读；关键字段/页面身份不明时AI补读；TS保存证据。 通过条件：目标仍存在、剩余额度大于0，要求在允许范围内。

2. **动作前检查**：定位目标时重新截图；任务与按钮唯一对应、当前可见无遮挡。滚动后旧坐标作废。 工具：OCR文字框+当前行关联；歧义时AI识图；统一Portal/ADB动作通道。 通过条件：没有未解决的前次动作，也无登录/验证/授权提示。

3. **取得回执**：在目的页保存属于本attemptId的明确完成原文和截图；没有回执返回unknown，不因等够时间或通用“已完成”报成功。 工具：OCR；页面复杂/提示不清时AI补读。 通过条件：本次任务及其完成条件可确认。

4. **返回与核验**：已确认任务目的页时，每次返回后先观察，再决定是否再返回；最多3次。到正确面板/资产页读目标次数与稳定余额。 工具：统一调度器返回；OCR读当前状态，必要时AI确认页面。 通过条件：回执、任务状态及资产证据一致；行被替换需用旧身份和本次回执核验，不能执行新行。

5. **保存结果并更新计划**：TS计算真实余额变化，保存回执/截图/次数/成本/状态；证据满足现有收益门禁才允许入账。更新该项剩余次数和后续计划版本。 工具：TS/SQLite；不由AI编造收益或写成功状态。 通过条件：已完成/无效果/未知/失败分开记录。追加次数须有新计划；发生未知动作或错误页时停止后续执行。
