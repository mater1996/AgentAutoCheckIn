## 本轮目标

用户确认继续：修复通用执行收尾，从正常入口自动收齐列表、选一项普通任务、执行取证、返回、更新状态和下一计划。最多一次任务，定时任务暂停。

## 之前与现在

| 之前 | 本轮修改 |
| --- | --- |
| 通用aiAct同时打开、完成、返回，无法在返回前保存完成回执 | 分段打开→读取目的页实际说明→执行一次并留在目的页→独立读取完整完成原文、绑定attempt→返回 |
| 兜底步骤错误仍可能被loop计为ok | 通用执行返回结构化workflow结果，错误保留；失败停止后续任务 |
| 面板判断只问布尔、恢复使用旧坐标 | 一次读取panel/blocked/identity；仅明确非面板且无遮挡才恢复一次；依配置实际入口 |
| 结算无条件back关掉面板 | 面板已确认后直接读同口径余额 |
| 后续清单和计划要监督另启动 | 正常入口执行一批后收齐新清单、评估并保存run-N-next.json；不覆盖原计划，不执行下一建议 |

完成提示全文来自既有真机观察，配置在活动task.completion_markers；不按任务名称猜模式，不通过模糊“已完成”判断。
