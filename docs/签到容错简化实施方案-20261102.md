## 之前与现在

| 环节 | 之前的问题 | 此次实施方向 |
|---|---|---|
| OCR采集 | 无关商品文字框越界导致所有文字作废 | 原始文字保留用于观察；只有动作坐标需合法，异常行单独记录 |
| 完成回执 | 依赖整图OCR健康、历史组件像素和位置；AI也被OCR错误否决 | 当前已打开任务的新截图中，明确完成关键词优先；读不清/歧义由AI看原图接手 |
| 其他页面步骤 | 旧文案、商品授权字样、固定几何可能干扰业务判断 | 审查导航、全列表采集、选择、要求、执行、返回、结算，按该步用途缩小判断范围 |
| 点击动作 | 观察结果与动作坐标混用 | 检查当前真正要点的目标及所在应用账号，错误结果未知时不重复派发 |
| 收益结算 | 需要当前任务回执和正确余额 | 保留同次任务归属及返回正确金币页的实际余额增量，不拿其他奖励数当余额 |

关键词无需把动态商品内容、历史截图配色、奖励提示的固定坐标作为前提。未完成/尚未完成等否定语句不能按子串误作成功；没有明确结果时进入现有AI观察路径。任务名不作为安全授权或流程推断。

## 一个任务的执行顺序

1. 收集当前完整清单，按本批记录排除已尝试任务，确定本次要做的一项。
2. 当前画面找到对应入口，点击后确认普通浏览要求，复用已学等待或连续滑动流程。
3. 新截图OCR匹配明确完成提示，记录截图和回执；文字不足时让AI看原图及本次操作上下文。
4. 返回金币页，核对实际余额后记账，归档实际采用脚本与观察证据。
5. 更新剩余计划，每项本批最多尝试一次，最后息屏。
