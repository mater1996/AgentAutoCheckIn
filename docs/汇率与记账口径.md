# 汇率与记账口径

调研时间：2026-10-29
用途：把签到得到的积分/金币/红包，折算成人民币记账。

---

## 一、已查到的汇率

| 单位 | 折算 | 来源 | 备注 |
|---|---|---|---|
| **淘金币** | **100 淘金币 = ¥1** | 淘宝官方「玩转淘金币」页、淘江湖问答 | 日常通用抵扣比例。单笔订单最高抵扣订单金额 20% |
| **京豆** | **100 京豆 = ¥1** | 京东帮助中心、百度百科 | 单笔最高抵扣 50%（随京享值升至 90%）；每单需 ≥500 或 1000 的整数倍 |
| **淘宝签到红包** | 面额即价值 | 淘宝活动页 | **不能提现**，只能购物抵扣；实测每次约 0.3~1 元 |
| **支付宝积分** | 视兑换项 | — | 无常量比例，按具体兑换商品定 |
| **美团神券** | 按券面额 | — | 满减券价值需按「实际省下」算，不是面额 |

### 关键发现：京豆 2026 新规

京东公告（2025-11-28 发布，2026-01-01 生效）：

> 1. 京豆**有效期最长不超过 180 天**。基础购物/评价/晒单获得的京豆有效期均为 180 天；
>    特定营销活动有效期一般 1 天到 180 天不等。
> 2. 使用京豆支付的订单取消或退货，若京豆仍在有效期内则退回，**有效期不变**。

**对记账的影响**：京豆会过期作废。账本不能只累加「赚了多少」，还要能算「还有多少没过期」。
否则累计收益会虚高。

## 二、记账口径（三个必须区分的概念）

签到得来的东西**不是同一种资产**，混在一起算会得出错误的收益结论。

| 口径 | 含义 | 例子 | 能否提现 |
|---|---|---|---|
| **账面价值** | 按官方汇率折算的名义金额 | 100 京豆 = ¥1 | ❌ |
| **可用价值** | 实际能抵掉多少钱（受抵扣上限约束） | 京豆单笔只能抵 50%，买 100 元最多抵 50 元 | ❌ |
| **现金** | 真能到账的钱 | 极少，多数平台签到不给现金 | ✅ |

**结论：签到收益基本全是「账面价值」，不能当现金算。**

所以账本要记三个字段，而不是一个 `cny`：

```json
{
  "reward": {"unit": "淘金币", "amount": 10},
  "face_value_cny": 0.10,        // 账面价值 = amount × cny_per_unit
  "usable_cny": 0.10,            // 可用价值（考虑抵扣上限，通常≈账面）
  "cash_cny": 0.0,               // 真现金（签到场景基本为 0）
  "expires_at": null             // 有效期（京豆 180 天）
}
```

**汇总时默认用 `face_value_cny`**，并明确标注「账面价值，不可提现」。
面板上两个数字都显示，避免把账面当现金自我欺骗。

## 三、有效期处理

| 单位 | 有效期 | 处理 |
|---|---|---|
| 京豆 | 最长 180 天（2026 新规） | 账本记 `expires_at`，面板显示「X 天后过期」 |
| 淘金币 | 长期（宝箱有容量上限，不领会不累积） | 无需过期处理，但**当天不领就少赚** |
| 淘宝签到红包 | 通常 7~15 天 | 记 `expires_at` |
| 美团神券 | 按券 | 记 `expires_at` |

**「今日不领就损失」比「过期作废」更紧迫** —— 宝箱容量满后不再累积，所以每日执行率才是收益的关键指标。

## 四、淘宝的五个签到入口（调研结果）

来源：知乎《淘宝领红包和优惠券的9种方法》、CSDN 实测记录、淘宝官方页

| 入口 | 位置 | 收益 | 备注 |
|---|---|---|---|
| **红包签到** | 首页图标 | 现金红包，约 0.3~1 元 | **有「翻倍」陷阱**：翻倍后只能在指定专区下单抵扣，不翻倍才全站通用 |
| **淘金币签到** | 淘金币频道「每日打开宝箱」 | 金币 | 宝箱有容量上限，满后不再累积 |
| **芭芭农场** | 首页图标 | 农场果实/红包 | 需多次交互，可能看视频 |
| **现金签到** | 我的淘宝 | 小额现金/红包 | 入口有时不开放 |
| **有好券签到** | 「有好券」栏目内 | 红包最多 5 元 | 只能在该栏目内用，不能提现 |

**建议 P1 只做前两个**（红包签到 + 淘金币），因为：
- 入口稳定、单步操作、无多轮交互
- 收益是淘宝签到里最大的两块
- 芭芭农场要多次交互 + 可能看视频，属于二期

**重要提醒**：红包签到出现「翻倍」弹窗时**不要点**，否则红包只能在指定专区使用，实际价值大幅缩水。

## 五、汇率维护策略

用户已定：**由我抓互联网数据算，不手填。**

做法：
1. 汇率存在 `activities/<app>.yaml` 的 `reward.cny_per_unit`，这是唯一折算入口
2. 我定期（建议每月）抓官方规则页，比对是否有变
3. 变了就改 YAML 一行，**历史账本不受影响**（账本写的是当时的 `face_value_cny`）

抓取来源（按可靠性排序）：
| 单位 | 抓哪里 |
|---|---|
| 淘金币 | 淘宝官方 `taobao.com/markets/taojinbi/*` |
| 京豆 | 京东帮助中心 `help.jd.com` |
| 其他 | 对应平台规则页 |

**注意**：官方页面可能改版或需登录，抓不到时退回「沿用上次值 + 标记 `stale`」，不要瞎猜。
