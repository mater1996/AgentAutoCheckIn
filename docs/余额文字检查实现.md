# 余额文字检查实现

当前入口 `readBalanceComponent` 默认且只产生 `ocr-region-v5`；设备原有 capture 调用无需改动。run216 先 RED：真实 PNG 被旧 reader 以 `Unknown or ambiguous digit glyph pixels differ` 拒绝；改动后同一原图通过真实本地 Apple Vision crop OCR 读出 2265，`verifiedBalanceValue` 与独立 audit 均接受。原 run216 仍为历史失败，本次不修改历史文件、不产生收益或完成结论。

## v5 规则

- 限定 1080×2400、`com.taobao.taobao/u0`，唯一指定位置「赚金币抵钱」，全部 OCR bounds 合法，无登录/验证/授权文字。
- 数字 ROI 固定 `{left:86,top:238,width:128,height:70}`，白色前景 mask 后放大 4 倍。前景列投影仅检查完整性与当前容量，不识别任何数字形状、不查旧 PNG、coin/arrow/title 像素或 glyph 库。必须有四个完整前景段，各边留至少 2 个原图像素空隙；触边、非四段拒绝。
- 当前实测容量只支持四位正整数。crop raw 必须来自 Apple Vision，唯一 page、唯一 line、精确 crop file/512×280，文本满足 `^[1-9][0-9]{3}$`，bounds 在 crop 内并留至少 4 个放大后像素边界。不能裁长数字取四位、取数字子串、去金额符号、去空白、合并多组数字或归一化全角。
- 原整图 `.ocr.json` 必须存在、绑定原 PNG，当前 frame 与原 raw 对应区域及标题逐项一致。与数字 ROI 相交的整图行必须唯一，完整文本是四位数字，或明确附着 `>`/`›` 箭头；后者 bounds 必须跨出数字 ROI 至箭头区域，右界不超过 242。纯数字右界不超过 214；两者左界在 86..110、上下界在 238..308。完整数字必须与 crop OCR 相同。整图文字只作冲突/容量 veto，不能独立提供余额。`#`、`無` 等任意后缀不被猜成箭头。
- 邻近人民币金额位于 ROI 外，不参与余额读取；相邻金额修改的合成测试仍读出真实 crop 的 2265。

## 证据和审计

沿用原 `BalanceComponentResult` 字段、frameId、原 PNG hash、ROI、cropHash、crop/raw 路径及 raw hash/text/bounds；新增可选 `fullFrameOcrEvidence:{path,sha256}` 绑定原整图 OCR。v5 不生成 glyph/reference 字段。原始文件只读；所有测试副本/crop/raw 输出在 `$TMPDIR` scratch，来源 PNG/JSON/raw 前后 SHA 均有断言。

`verifiedBalanceValue` 每次同步验证原 PNG、crop、两份 raw 的 hash、frame/owner/version/value/bounds 与唯一整数/冲突规则。它不异步解码原 PNG。独立 `verifyAuditBalanceComponent` 受 EvidenceReader 路径约束，从原 PNG 重新生成相同 crop、逐 byte 对比保存 crop，重新验证保存 raw/value/ROI/frame/owner/page；v5 审计不调用 OCR，也不写任何证据。不能把修改 crop 后重新填 hash 当作审计通过；修改 raw 并同步改 value 会被原整图对应区域冲突拒绝。

两份 OCR 都来自同一帧，不是独立真实性证明；hash 是完整性校验，不是签名。如果所有 PNG、两份 raw 和元数据都被一致伪造，当前无签名档案不能证明来源真实。仅像素变化而 OCR 完全不变的图标/标题遮挡已不承诺由余额 checker 识别；面板身份由独立面板文字 checker 负责。

## 历史兼容

保留显式 `readLegacyBalanceComponent` 与 `LEGACY_BALANCE_COMPONENT_VERSION='original-glyph-composition-v4'`。原 glyph/chrome/source 验证逻辑不变。独立 audit 按 evidence.version 分派；v4 仅走原 glyph 重放，v5 走文字规则，不给旧 run 升级标签。`verifiedBalanceValue` 可消费通过旧证据完整性条件的 v4，以支持历史回放；当前 device 默认 reader 始终输出 v5。

有些旧图的整图 raw 是 `2135#`、`2050無`，跨入邻近文字区域；v5 明确拒绝它们。旧 `staged-balance-*` 测试中，复制 PNG 后不复制原 full raw、要求产生 glyph 字段、要求任意像素变化都在 OCR 前拒绝、或要求这些歧义整图前缀成为余额的断言已过时。按委派边界未改旧 tests/runtime/device。
